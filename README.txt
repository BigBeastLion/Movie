MOVIE ROULETTE — PRIVATE-DATA VERSION

The app source contains no movie-list entries.
Upload this folder to a static HTTPS host to publish the app shell.
Keep your private movie-list JSON file separate and do NOT upload it.
Open the hosted app, go to Library > Data & backup > Import my 315 entries,
and select the separate JSON file. The list is then stored in this browser/device.

Your entries are not sent to the hosting provider by this app; they remain in
browser local storage. There is no cross-device sync. Export JSON backups regularly.
